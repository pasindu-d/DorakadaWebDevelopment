# Dorakada Web Development

Portfolio website for Dorakada Web Development: websites for villas and guesthouses worldwide.

A plain static site (HTML and CSS, no build step).

## Files

- `index.html`: the whole page
- `assets/villa-homepage.jpg`: Elephant Beach Villa screenshot
- `favicon.svg`: browser tab icon

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**. Leave build and output settings empty.
4. Click **Deploy**.

Every push to the main branch redeploys the site automatically.
